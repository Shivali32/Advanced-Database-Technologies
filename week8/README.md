# Week 8: Data Cleaning and MongoDB Imports

Prepare CSV data for MongoDB and explore document queries with PyMongo.

## How It Works

The sales notebook removes formatting characters from numeric values before loading records into a collection. Additional notebooks demonstrate MongoClient connections, collection exploration, and COVID-related queries.

## Main Tasks

- Read the source CSV and inspect column types.
- Clean numeric strings before database insertion.
- Query and inspect the imported documents through PyMongo.
