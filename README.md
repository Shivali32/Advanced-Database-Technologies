# Advanced Database Technologies

This repository contains twelve weeks of database coursework using SQL scripts, Python notebooks, CSV datasets, and written lab submissions. The early weeks focus on relational tables, SQLite and Python data loading, PostgreSQL types and views, foreign keys, normalization, metadata, and indexes. The next group introduces MongoDB documents, PyMongo queries, and data cleaning before import. Later exercises use Neo4j and Cypher for graph modeling, movie and rating relationships, recommendations, and network traversal. The final week introduces Cassandra keyspaces, tables, and CQL. The weekly folders keep source data beside the notebooks or reports that use it.

## Assignments and Labs

- **[Week 1: Relational Tables and SQL](week1/)**  
  Create relational tables and practice selection, filtering, aliases, and calculations on employee and department data.

- **[Week 2: SQLite and Python Data Loading](week2/)**  
  Load CSV data into SQLite and query it from Python notebooks.

- **[Week 3: PostgreSQL Types Views and Joins](week3/)**  
  Explore relational types, views, materialized views, and joins using PostgreSQL and sample relational data.

- **[Week 4: Constraints Metadata and Normalization](week4/)**  
  Examine foreign-key behavior, database metadata, SQL functions, and normalized tables.

- **[Week 5: Indexes and Query Practice](week5/)**  
  Compare index structures and practice queries over a relational schema.

- **[Week 6: MongoDB Documents](week6/)**  
  Introduce document databases through MongoDB setup and movie-data queries.

- **[Week 7: MongoDB and Python](week7/)**  
  Use document-oriented queries and a Python notebook to work with MongoDB collections.

- **[Week 8: Data Cleaning and MongoDB Imports](week8/)**  
  Prepare CSV data for MongoDB and explore document queries with PyMongo.

- **[Week 9: Neo4j and Query Translation](week9/)**  
  Explore graph databases and compare document filters with relational query expressions.

- **[Week 10: Graph Recommendations and Cypher](week10/)**  
  Load related data into Neo4j and examine graph queries and recommendation calculations.

- **[Week 11: Graph Modeling and Network Queries](week11/)**  
  Model student data and query a network-management graph.

- **[Week 12: Cassandra and CQL](week12/)**  
  Work with Cassandra through a Python notebook and DataStax Astra connection setup.
