# Week 3: PostgreSQL Types Views and Joins

Explore relational types, views, materialized views, and joins using PostgreSQL and sample relational data.

## How It Works

The lab document describes type experiments and hospital-count views. The doctor database script and Sakila schema/data files provide SQL examples and data for the submitted query practice.

## Main Tasks

- Inspect table definitions and key relationships.
- Compare views and materialized views.
- Use selection and join queries to combine related records.
