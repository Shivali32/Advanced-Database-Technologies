# Week 2: SQLite and Python Data Loading

Load CSV data into SQLite and query it from Python notebooks.

## How It Works

The notebooks connect through sqlite3, use pandas to read Netflix and Spotify data, and write tables with DataFrame.to_sql. A separate coding-practice notebook works with employee and department records.

## Main Tasks

- Read the included CSV datasets.
- Create SQLite connections and populate tables.
- Run SQL through notebook cells and inspect the returned rows.
