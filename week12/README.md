# Week 12: Cassandra and CQL

Work with Cassandra through a Python notebook and DataStax Astra connection setup.

## How It Works

The notebook describes keyspaces, connection configuration, table creation, and queries over supplied records. The CSV and written submission accompany the CQL and Python exercises.

## Main Tasks

- Configure the course Cassandra connection.
- Create the required keyspace or tables.
- Load records and inspect CQL query results.

## Files

- [shimate_ADT_Lab_12.ipynb](shimate_ADT_Lab_12.ipynb): notebook containing analysis code and written explanations.
- [Week_12_Coding_Practice_Submission.docx](Week_12_Coding_Practice_Submission.docx): editable assignment or report document.
- [hw_200-1.csv](hw_200-1.csv): tabular input data.
- [shimate_ADT_Lab_12.html](shimate_ADT_Lab_12.html): exported notebook or browser-viewable visualization.

## Connection Files

Use your own Astra database connection bundle and application token when running the notebook. Keep the bundle and token files local, and configure the notebook connection for your database before executing its cells.
