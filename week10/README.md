The notebook reads movie and rating data, creates graph entities through py2neo, and uses cosine similarity for recommendation-related analysis. The week also includes Cypher practice and datasets for additional graph tasks.

## Main Tasks

- Load the relevant CSV inputs.
- Create nodes and relationships in the course Neo4j database.
- Inspect graph query results and similarity calculations.
