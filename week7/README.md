# Week 7: MongoDB and Python

Use document-oriented queries and a Python notebook to work with MongoDB collections.

## How It Works

The notebook demonstrates a MongoDB connection and document operations. The week also includes a sales dataset and written practice material covering the document model and query examples.

## Main Tasks

- Inspect collection records and their field types.
- Run the notebook queries against the intended lab database.
- Compare the resulting documents with the report examples.
