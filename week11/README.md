# Week 11: Graph Modeling and Network Queries

Model student data and query a network-management graph.

## How It Works

The homework records student-graph import statements and uniqueness constraints. The coding-practice document explores data centers, routers, interfaces, racks, switches, and shortest paths through a network graph.

## Main Tasks

- Map dataset fields into graph entities and relationships.
- Apply uniqueness constraints during import.
- Traverse network relationships and inspect shortest paths.
