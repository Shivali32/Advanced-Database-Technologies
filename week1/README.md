# Week 1: Relational Tables and SQL

Create relational tables and practice selection, filtering, aliases, and calculations on employee and department data.

## How It Works

SQL files define the analysis database and query exercises, while CSV inputs provide employee and department rows. The accompanying documents explain the initial database workflow.

## Main Tasks

- Create the required database and tables.
- Load employee and department CSV records.
- Run the query examples and compare their result shapes.
