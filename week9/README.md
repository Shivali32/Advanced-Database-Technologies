# Week 9: Neo4j and Query Translation

Explore graph databases and compare document filters with relational query expressions.

## How It Works

The lab and practice reports introduce nodes, relationships, and Cypher patterns using a movie graph. The homework translates MongoDB-style conditions into SQL, and the accompanying data files support the graph exercises.

## Main Tasks

- Describe entities and relationships as a graph.
- Use MATCH and WHERE patterns to retrieve related records.
- Compare document queries with equivalent relational conditions.
