# Week 4: Constraints Metadata and Normalization

Examine foreign-key behavior, database metadata, SQL functions, and normalized tables.

## How It Works

The SQL scripts create and populate a linked schema. Notebook and report exercises inspect information_schema, manipulate strings and numbers, and query normalized hospital and doctor records.

## Main Tasks

- Create the schema and populate its related tables.
- Observe referential behavior when records change.
- Inspect metadata and run the normalization and query exercises.
